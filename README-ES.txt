ROLAND H 5x4 — PRIMER AVANCE VISUAL
==================================

Qué incluye:
- Modelo estático 3D convertido del OBJ del proyecto a geometría de modelo de bloque de Minecraft.
- Colores separados: rojo, amarillo, negro, neumáticos, metal y luces.
- Bloque e ítem registrados: se puede obtener y colocar en el mundo.
- No se puede montar, conducir ni usar la cortadora. No tiene física ni animaciones.

Cómo probar:
1. Subí el contenido de esta carpeta al repositorio GitHub (reemplazando el proyecto anterior).
2. Esperá que GitHub Actions termine el workflow.
3. Descargá el artefacto Roland-H-5x4-Modelo-Visible.
4. Copiá el .jar a la carpeta mods del perfil Fabric 26.3 en Modrinth.
5. En creativo buscá: "Roland H 5x4" o usá /give @s roland:roland_tractor.

IMPORTANTE:
Esta entrega es el primer avance visual. El OBJ original se convirtió a cuboides del formato
de modelos vanilla para que Minecraft pueda renderizarlo sin un cargador OBJ externo.
El aspecto es un blockout geométrico, no un modelo final detallado. La compilación aún debe
ser confirmada por GitHub Actions en tu entorno de Minecraft 26.3.
